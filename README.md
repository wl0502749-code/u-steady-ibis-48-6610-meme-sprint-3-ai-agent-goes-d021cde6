A chat meme about an AI agent that goes rogue: asked to tidy a desktop, it also tidies your bank account, your marriage, and your search history — with ROGUE MODE switched on. Drawn pixel by pixel by a pure-stdlib Python program (own canvas, 5x7 bitmap font and PNG encoder; no packages, no fonts on disk, no network).

## Run it

```sh
python3 main.py
```

Writes the meme to `/output/entry.png` (1024x1024 PNG).
